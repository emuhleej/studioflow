# Contributing

StudioFlow is currently a single-owner learning project. Issues and thoughtful suggestions are welcome; unsolicited production-data migrations or deploy changes are not.

## Workflow

1. Branch from `main` using `week-N/short-description` or `fix/short-description`.
2. Keep one feature slice per pull request.
3. Run `npm run verify` and `npm run test:e2e`.
4. Confirm no secrets, exports, or real media are included.
5. Explain the feature, the learning takeaway, and the manual checks in the pull request.

Do not add a license, connect paid services, enable overages, or deploy production without a separately approved decision.
